# Ricochet Rush — Team FPS Prototype

A lightweight browser FPS prototype built with Three.js.

## Features
- First-person / third-person camera switch (V on desktop or on-screen button)
- 5v5 team match: choose Blue or Red in the deployment menu
- Four AI teammates and five enemy bots
- Bots target opposing players/bots, move, strafe, and fire when they have line of sight
- Mobile left joystick, right-side drag aim, and drag-to-aim while holding FIRE
- Automatic fire, recoil, reload, synthesized sound effects, health/ammo HUD

## Run
Open `index.html` from a local web server or publish the folder with GitHub Pages. An internet connection is required to load Three.js from its CDN.

## Controls
- Desktop: WASD, mouse aim, hold left mouse to fire, R reload, Shift sprint, Space jump, V switch camera, Esc pause/release mouse
- Mobile: left joystick to move, drag right side to aim, drag FIRE button to aim while firing, JUMP/RUN/RELOAD buttons, 1P/3P button to switch camera

This is a prototype; it has AI opponents and no online multiplayer.
